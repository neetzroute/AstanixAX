# Astanix-AX

**Astanix-AX** — высокопроизводительный Paper-плагин для Minecraft 1.21.x (Java 21), предназначенный для административного анти-рентгена и проверки подозрительных игроков на использование X-Ray читов.

---

## ⚡ Особенности и архитектура

1. **Модульная сервисная архитектура:**
   - `gui` — Интуитивный инвентарный интерфейс с пагинацией, фильтрами по типам руды и статусу проверок.
   - `tracker` — Слушатель добычи руды и spatial-кластеризация рудных жил в реальном времени.
   - `highlight` — Персональная сетевая подсветка блоков (`GOLD_BLOCK`) через клиентские пакеты обновления блоков Paper API (`Player#sendBlockChange`).
   - `storage` — Асинхронное локальное хранилище SQLite на пуле HikariCP с поддержкой WAL и индексами по игрокам и статусам.
   - `command` — Командный интерфейс `/ax` с таб-комплишеном и проверкой прав.

2. **100% TPS-Safe & Асинхронность:**
   - Никаких блокировок главного тика сервера (`AsyncScheduler`, `CompletableFuture`).
   - Игровой мир остается полностью неизменным: подсветка кладок руды видна **только** проверяющему администратору.
   - Автоматический сброс подсветки при телепортации, смене мира, закрытии сессии или выходе администратора.

3. **Кластеризация руды:**
   - Руды, добытые в радиусе кластеризации (по умолчанию 3.5 блоков), объединяются в единые кластеры (кладки).

4. **Персистентная отметка «Чисто»:**
   - Администратор может кликом мыши (ПКМ в GUI или кнопкой в чате) пометить кладку проверенной.
   - Статус сохраняется в базе данных между перезагрузками сервера.

## 🎮 Команды и права

| Команда | Описание | Право доступа |
|---|---|---|
| `/ax` или `/astanixax` | Открыть главное меню со списком игроков | `astanix.axray.admin` |
| `/ax inspect <игрок>` | Открыть список кладок конкретного игрока | `astanix.axray.admin` |
| `/ax clear` | Сбросить активную подсветку блоков и вернуть исходный вид | `astanix.axray.admin` |
| `/ax reload` | Перезагрузить файл конфигурации `config.yml` | `astanix.axray.admin` |

## 📦 Сборка проекта

### Требования:
- Java Development Kit (JDK) 21+
- Apache Maven 3.9+ или Gradle 8+

### Сборка через Maven:
```bash
mvn clean package
```
Готовый плагин появится в: `target/astanix-ax-1.0.0.jar`.

---

## ⚙ Конфигурация (`config.yml`)

Плагин генерирует подробный конфигурационный файл с настройками:
- Имя файла базы данных SQLite и параметры пула HikariCP.
- Радиус кластеризации и временное окно сессии добычи.
- Блок подсветки (по умолчанию `GOLD_BLOCK`).
- Автоматический переход в режим наблюдателя (`SPECTATOR`) при инспекции.
- Полная кастомизация сообщений в формате MiniMessage.
